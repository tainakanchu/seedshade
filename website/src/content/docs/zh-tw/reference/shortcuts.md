---
title: 鍵盤快捷鍵
description: 主視窗與 Scene Deck 視窗的鍵盤快捷鍵一覽。
---

在任何一個視窗中，當焦點在文字輸入欄、選擇欄時，以及按住 `Ctrl` / `Alt` / `⌘` 時，這些按鍵都不會作用。

## 主視窗

| 按鍵 | 動作 |
| --- | --- |
| `H` | 顯示 / 隱藏面板（控制面板 + Timeline 面板） |
| `F` | 切換全螢幕 |
| `B` | 背景在黑色 ⇄ 透明之間切換 |
| `R` | 重抽種子（🎲） |
| `D` | 保持相同構成，只重抽細節（🧬） |
| `S` | 開啟 Scene Deck 視窗（已開啟的話就拉到最前面） |
| `T` | Tap tempo |

在種子輸入欄按 `Enter` 確定。

## Scene Deck 視窗

| 按鍵 | 動作 |
| --- | --- |
| `1`～`8` | 輸出欄位（使用選取中的過渡預設組） |
| `Shift` + `1`～`8` | 以 `cut` 輸出欄位 |
| `←` `→` `↑` `↓` | 移動游標（4 × 2） |
| `Enter` / `Space` | 輸出游標所在的欄位 |
| `X` | 依 `cut` → `default` → `slow` 切換過渡預設組 |
| `Q` | 重抽種子（相當於主視窗的 `R`） |
| `W` | 只重抽細節（相當於主視窗的 `D`） |
| `B` | 背景在黑色 ⇄ 透明之間切換 |
| `H` | Hue 固定 ⇄ 循環（切換為固定時，以目前的色相固定） |
| `[` / `]` | 固定 Hue 減少 15° / 增加 15° |
| `T` | Tap tempo |
| `,` / `.` | 節拍 ÷2 / ×2 |
| `/` | 節拍回到自動偵測（AUTO） |
| `L` | 將 Timeline 從現在起鎖定 30 秒 ⇄ 解除 |
| `A` | 自動換場 ON / OFF |
| `M` | 自動換場的單位（秒 ⇄ 小節） |
| `-` / `=` | 減少 / 增加自動換場的間隔（數字鍵台的 `-` / `+` 也可以） |
| `R` | 從主視窗目前的 Patch 重新建立 Bank |
| `G` | BASE 維持不變，只重抽 Bank 的亂數 |
| `Shift` + `S` | 將目前的手牌存進下一個空欄位（沒有的話存進 `A`） |
| `F` | Deck 視窗的全螢幕 |
| `Esc` | 結束 MIDI learn |

:::note[日文（JIS）配置的鍵盤]
Deck 的按鍵不是依字元，而是依按鍵的實體位置（以美式鍵盤配置為準）判定。
在 JIS 配置下，`[` → **`@`** 鍵，`]` → **`[`** 鍵，`=` → **`^`** 鍵的位置。`,` `.` `/` `-` 則與鍵帽刻印相同。
`1`～`8` 是鍵盤上排的數字鍵（無法使用數字鍵台的數字）。
:::

### 滑鼠操作（Deck）

| 操作 | 動作 |
| --- | --- |
| 點擊欄位 | 輸出該欄位 |
| 點擊 `A`～`H` | 叫出該手牌 |
| `Shift` + 點擊 `A`～`H` | 儲存目前的手牌（不會確認是否覆寫） |
| 對 `A`～`H` 按右鍵 / 長按 | 編輯手牌的名稱 |
