Seedshade 的外觀由**種子（字串）**決定。
一換種子，Generator 的組合、參數、配色、構圖，乃至對聲音的反應方式都會一併改變，畫面就像抽扭蛋一樣整個換掉。我們稱之為 **look gacha**。

## 基本概念

- 相同的種子**一定能重現相同的外觀**。遇到喜歡的畫面時，請記下面板 **Look** 上顯示的種子字串。
- 種子字串的「意思」並不會被解讀。`humid-night-market` 和 `take-3` 只是不同的亂數種子而已。名稱只是讓你自己方便回想的索引。
- 切換不是硬切，而是以淡入淡出平滑過渡。

## 🎲 與 🧬 的差別

| 操作 | 按鍵 | 會改變什麼 |
| --- | --- | --- |
| 🎲 重抽種子 | `R` | **全部**。從 Generator 的組成（用哪些零件、怎麼疊）開始就不同。新的種子會反映在面板的 Look 並被儲存。 |
| 🧬 只重抽細節 | `D` | Generator 的組成**維持不變**，只用新的亂數重抽參數、聲音調變的連結、配色與構圖。 |

🧬 適合用在「形狀很喜歡，但想換顏色或動態」的時候。
由於組成不變，拍點時發生的故障特效種類（[音訊反應](../semantic-synth/#3-拍點觸發的效果)）也不會改變。

:::note
用 🧬 重抽的結果不會被存成種子（面板 Look 的顯示也不會改變）。
重新載入頁面後，會回到 Look 所顯示之種子的外觀。
:::

## 手動輸入種子

1. 在 **Look** 那一列的輸入欄中輸入種子字串（最多 64 個字元）。
2. 按 **Enter**，或點擊輸入欄以外的地方就會套用（不是每輸入一個字就反映）。

若在空白的狀態下確定，會回到原本的種子。
也可以用 URL 的 `?seed=…` 指定啟動時的種子（[URL 參數](../../reference/url-params/)）。

## 自動重抽

將 **🎲 Auto-gacha** 設為 `On`，就會每隔指定的小節數自動重抽種子。
只有在節拍已鎖定（或已用 Tap 設定）時才會計數。→ [節拍同步](../tempo/#每-n-小節自動抽一次)

## 想要特定氛圍時

種子是完全隨機的，所以無法刻意抽出「潮濕夜晚感的畫面」。如果有明確的目標，可以用下列方法。

| 方法 | 說明 |
| --- | --- |
| Scene Deck | 以目前的畫面為基準，產生組成相同、僅參數不同的 8 格並一鍵切換。→ [Scene Deck](../../live/scene-deck/) |
| `vj:gen`（CLI） | 從 `雲 静寂 青` 這類情緒關鍵字（日文詞彙）生成 Patch。→ [vj:gen / vj:tweak](../../ai/gen-tweak/) |
| 配方（CLI） | 以 JSON 儲存「情緒關鍵字 + 種子 + 微調」，隨時都能重新做出來。儲存庫的 `recipes/` 有 30 個以上的範例。→ [vj:recipe / vj:set](../../ai/recipe-set/) |
| 直接撰寫 Patch | 在 Timeline 面板的 **Patch** 欄編輯 JSON 後按 `Apply`。→ [Timeline 面板](../timeline/#patch直接編輯目前的-patch) |
