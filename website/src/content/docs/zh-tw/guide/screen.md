主視窗中，在全螢幕的視覺畫面上疊著 2 個面板。

- **左上：控制面板**（`SEEDSHADE`） — 音訊輸入・節拍・種子・顏色・背景等基本操作
- **右上：Timeline 面板** — 預約事件・直接編輯 Patch・圖片・錄製等進階操作（[Timeline 面板](../timeline/)）

## 顯示 / 隱藏面板

| 狀態 | 操作 | 說明 |
| --- | --- | --- |
| 隱藏 / 顯示 | **`H`** | **同時**隱藏控制面板與 Timeline 面板。再按一次即恢復。 |
| 一開始就隱藏 | URL 加上 `?ui=hide` | 適用於 OBS 或正式輸出。可用 `H` 叫出。 |
| 自動淡出 | 滑鼠停止約 3 秒 | **只有控制面板**會變透明，滑鼠游標也會消失。移動滑鼠、點擊或按下按鍵就會恢復。 |
| 收合 Timeline | Timeline 的 `▾ close` | 變成只剩標題的小顯示。按 `▸ open` 即恢復。 |

:::caution
Timeline 面板不會自動淡出。正式輸出的畫面請用 **`H`** 或 `?ui=hide` 隱藏。
:::

## 控制面板的項目

由上而下依序排列。

| 項目 | 說明 |
| --- | --- |
| 標頭 | `live`（音訊輸入運作中）/ `idle`（已停止）。 |
| **▶ Click to start audio** / **■ Stop audio** | 開始 / 停止音訊輸入。啟動後沒有自動開始時，請按這裡。 |
| 音量表 | 套用 Gain 之前的輸入音量（dBFS）。有 -60 ～ 0 的刻度、目標區段（-18 ～ -6）與峰值保持線。 |
| `CLIP` | 輸入飽和時會亮起約 1.5 秒。 |
| 拍點燈 | 每偵測到一拍就會亮一下。 |
| `NO SIGNAL` | 音訊輸入明明在運作，卻幾乎無聲（低於約 -60 dBFS）持續 3 秒時顯示。 |
| `B` / `M` / `T` | 低頻・中頻・高頻的音量（套用 Gain 之後）。畫面就是依這些數值而動。 |
| **Tempo** | 目前的 BPM、狀態標籤（`LOCK` / `SEARCH…` / `TAP`）、小節內的拍位置（4 個點，最左邊是第 1 拍）、`TAP` `×2` `÷2` `AUTO` 按鈕。→ [節拍同步](../tempo/) |
| **Look** | 目前的種子、種子輸入欄、🎲（重抽種子）、🧬（只重抽細節）。→ [種子](../seed/) |
| **Input device** | 選擇音訊輸入裝置。運作中變更會立即切換。 |
| **Gain** | 分析用訊號的倍率（0.5 ～ 4，預設 1.5）。會改變畫面反應的強度。 |
| **Hue** | `Cycle`（色相持續緩慢轉動）/ `Fixed`（用滑桿固定在 0 ～ 360°）。 |
| **Background** | `Black`（黑色背景）/ `Transparent`（透明背景）。透明背景是用於疊在 OBS 上。→ [OBS](../../live/obs/) |
| **🎲 Auto-gacha** | 設為 `On` 後，每隔指定的小節數就自動重抽種子（1 ～ 512 小節，預設 32）。→ [節拍同步](../tempo/#每-n-小節自動抽一次) |
| **Scene Deck** | 開啟操作台的另開視窗。→ [Scene Deck](../../live/scene-deck/) |
| **⛶ Fullscreen** | 切換全螢幕。 |

面板的最下方會顯示快捷鍵的速查表。

## 主視窗的鍵盤快捷鍵

當焦點在文字輸入欄或選擇欄時，以及按住 `Ctrl` / `Alt` / `⌘` 時，這些按鍵不會作用。

| 按鍵 | 動作 |
| --- | --- |
| `H` | 顯示 / 隱藏面板（控制面板 + Timeline） |
| `F` | 切換全螢幕 |
| `B` | 背景在黑色 ⇄ 透明之間切換 |
| `R` | 重抽種子（與 🎲 相同） |
| `D` | 保持相同構成，只重抽細節（與 🧬 相同） |
| `S` | 開啟 Scene Deck 視窗（已開啟的話就拉到最前面） |
| `T` | 手動輕拍節拍（Tap tempo） |

Scene Deck 視窗有另外的快捷鍵。清單請參閱[鍵盤快捷鍵](../../reference/shortcuts/)。

## 把檔案拖放到畫面上

將圖片檔案（PNG / JPG / WebP / GIF / SVG / AVIF）拖放到主視窗的任何位置，就會登錄到 Timeline 面板的 **Images**。
如何把登錄的圖片放進畫面，請參閱 [Timeline 面板](../timeline/#images蓋印圖片)。
