Seedshade 會從輸入的聲音即時推算 BPM，建立拍與小節的網格。
這個網格會用於拍點觸發的故障特效、畫面速度、Auto-gacha、Timeline 以小節指定的事件，以及 Scene Deck 以小節為單位的自動換場。

## Tempo 區塊的看法

控制面板的 **Tempo** 會顯示下列內容。

| 顯示 | 意義 |
| --- | --- |
| BPM 數值 | 目前的 BPM。尚未偵測到時為 `—`。 |
| `SEARCH…` | 自動偵測中（尚未鎖定）。 |
| `LOCK` | 已由自動偵測確定節拍的狀態。 |
| `TAP` | 以 Tap 手動設定的節拍運作中。 |
| 4 個點 | 小節內的拍位置。最左邊（第 1 拍）會強調顯示。 |

## 自動偵測

- 從低頻（大鼓）的起音以自相關推算 BPM。**對大鼓規律的曲子（例如四四拍重拍）特別有效**。
- 分析至少需要 3 秒的聲音，到鎖定為止要花數秒。
- 推算範圍為 60～200 BPM，結果會以倍數 / 減半的方式收斂到 70～180 BPM 的範圍內。
  遇到半拍 / 倍拍的曲子而倍率與預期不符時，用 `×2` / `÷2` 修正。
- 一旦鎖定，網格就會**自行運轉**。即使在 Break（無聲段落）中也會持續打拍，曲子回來時再緩緩調整相位。

## 按鈕與按鍵

| 按鈕 | 按鍵 | 動作 |
| --- | --- | --- |
| `TAP` | `T` | 配合曲子敲 2 次以上，就會依間隔設定 BPM。間隔採用最近 6 次的中位數，間隔超過 2 秒就重新計算。即使聲音已停止，網格也會繼續轉。 |
| `×2` | — | 節拍加倍。 |
| `÷2` | — | 節拍減半。 |
| `AUTO` | — | 回到自動偵測（倍率也會回到 1 倍）。 |

`×2` / `÷2` 的倍率範圍是 0.25～4 倍。在 Scene Deck 視窗中也可以用 `,`（÷2）`.`（×2）`/`（AUTO）`T`（Tap）操作。

:::tip
對於大鼓不明顯的曲子（Ambient、Breakbeat、現場演奏等），自動偵測可能不穩定。
這種情況下用 `TAP` 手動設定最可靠。
:::

## 每 N 小節自動抽一次

將 **🎲 Auto-gacha** 設為 `On`，就會每隔指定的小節數自動重抽種子。

- 小節數用右邊的數值欄設定，範圍為 1～512 小節（預設 32）。1 小節 = 4 拍。
- **只有在顯示 BPM 數值時才會計數**。BPM 為 `—`（尚未偵測）時不會重抽。
  即使在 `SEARCH…` 中，只要有暫時的 BPM 值就會計算小節，所以想確實配合曲子的展開時，請確認為 `LOCK`，或用 `TAP` 對拍。
- 也可以用 URL 的 `?autogacha=1&gachabars=16` 指定。

## 與節拍相關的其他功能

| 功能 | 與節拍的關係 |
| --- | --- |
| Timeline 的 `+bars` 事件 | **只有在節拍網格已鎖定時（`LOCK` 或 `TAP`）**才會觸發。→ [Timeline 面板](../timeline/) |
| Scene Deck 以小節為單位的自動換場 | 只有在主視窗的節拍已鎖定時（`LOCK` 或 `TAP`）才會前進。→ [Scene Deck](../../live/scene-deck/#自動換場) |
| 畫面速度 | 鎖定中（包含 `TAP`）會依節拍在 0.7～1.25 倍之間變化。→ [Semantic Synth 的原理](../semantic-synth/) |
