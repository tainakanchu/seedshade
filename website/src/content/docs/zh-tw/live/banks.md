---
title: 儲存手牌（Bank）
description: 把 Scene Deck 的 8 格存進 A～H 欄位並叫出，或用 JSON 帶到別台電腦。
---

Scene Deck 的 8 格（BASE + V1～V7）稱為「手牌」。手牌除了自動儲存之外，也可以命名後存進 `A`～`H` 共 8 個欄位。

## 儲存的內容

儲存的只有**基準的 Patch（BASE）與變化用的亂數（bankSeed）**。
8 格本身不會被儲存，而是每次都從相同的輸入重新做出相同的 8 格。此外，也會一併儲存過渡預設組、自動換場的設定、游標位置，以及儲存當下主視窗的種子。

儲存位置是瀏覽器的 `localStorage`（key 為 `seedshade-deck-banks-v1`）。

## 自動儲存（防當機）

- 每當手牌、過渡預設組、自動換場、游標有變化，約 0.5 秒後就會自動儲存。
- 重新開啟 Deck 時，已儲存的手牌會**不等主視窗**，立刻還原。
- 如果一次都沒有儲存過，則會從主視窗目前的畫面建立手牌。

## A～H 欄位

使用工具列上 `A`～`H` 的小按鈕（空的欄位會以淡色顯示）。

| 操作 | 動作 |
| --- | --- |
| `Shift` + 點擊 | 把目前的手牌存進該欄位（**不會確認是否覆寫**） |
| `Shift` + `S` | 存進下一個空欄位（沒有空欄位時覆寫 `A`） |
| 點擊 | 叫出該欄位的手牌 |
| 右鍵 / 長按 | 編輯欄位名稱（按 Enter 確定，按 Esc 取消） |

:::caution[叫出手牌後，畫面不會馬上改變]
叫出欄位時，只會替換 Deck 的 8 格。主視窗的畫面要等到按下 Pad（`1`～`8` 等）才會改變。
儲存當下主視窗的種子也不會自動送出。想連種子一起還原的話，請按 `menu` 的 **seed を採用**（採用 seed；主視窗的種子設定與畫面都會切換）。
:::

## 用 JSON 帶走

要把手牌帶到別台電腦或別的瀏覽器時使用。

1. 按 `JSON copy`，目前的手牌就會複製到剪貼簿（顯示 `copied`）。
2. 在要帶過去的 Deck 開啟 `menu`，貼到文字欄後按 `JSON paste`。

:::note[圖片無法帶走]
Patch 裡面放的不是圖片本身，而只是圖片的參照（雜湊值）。圖片資料在瀏覽器的 IndexedDB（`seedshade-images`）裡。
只把 JSON 帶到別台電腦的話，stamp 的圖片會是透明的。請在對方那邊也從 Timeline 面板登錄同一張圖片（同一個檔案會得到相同的雜湊值）。
:::

## 出現 STALE 時

Seedshade 更新而 Generator 有變動時，已儲存的 BASE 可能會無法通過目前目錄的驗證。
這時會顯示 **STALE: generator 更新あり。R で live から取り直し**（STALE：Generator 已更新，按 R 從即時畫面重新取得）。

- Deck 不會當掉，但所有變化版本都會等同於 BASE。
- 請按 `R`，從主視窗目前的畫面重新建立手牌。

## 清除

在 `menu` 中依序按 `clear current` → `confirm clear current` 兩個步驟，就能清除自動儲存的手牌（current）。
下次開啟 Deck 時會從主視窗目前的畫面重新建立。`A`～`H` 的欄位不會被清除。
