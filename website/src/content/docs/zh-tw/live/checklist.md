---
title: 現場設定檢查清單
description: 正式演出前應該確認的事項。
---

這是避免在演出會場手忙腳亂的確認清單。請由上而下依序確認。

## 事前（在家裡）

- [ ] 用演出要使用的電腦與瀏覽器（建議 Chrome / Edge），確認 Seedshade 能夠繪圖（不會出現「WebGL2 が必要です」）。
- [ ] 用與正式演出相同的解析度，確認負載不會太重（Timeline 面板的 `quality` 沒有持續大幅下降）。
- [ ] 記下想用的種子。必要時把 Scene Deck 的手牌存進 `A`～`H`（[儲存手牌](../banks/)）。
- [ ] 如果要用 stamp 放 Logo，已在演出用的電腦、瀏覽器中登錄好圖片（圖片是依瀏覽器分別儲存的）。
- [ ] 如果要使用 MIDI 控制器，已在演出用的電腦上確認過對應（[MIDI 控制器](../midi/)）。
- [ ] 如果使用線上版，已確認會場能連上網際網路。若有可能連不上，已準備好本機版（`pnpm build` → `pnpm preview` 等）。

:::note
設定、手牌、MIDI 對應、圖片，都是**依瀏覽器與來源（URL 的網域）分別**儲存的。
在家用 `localhost` 準備好的內容，在線上版（`seedshade.tainakanchu.com`）是看不到的。請用與演出時開啟的相同 URL 來準備。
:::

## 會場：聲音

- [ ] 已將混音器的 Booth 輸出 / REC 輸出等接到音訊介面的線路輸入。
- [ ] 已在 **Input device** 選擇正確的輸入。
- [ ] 播放聲音後，音量表落在目標區段（-18 ～ -6 dBFS）內。`CLIP` 沒有亮起。`NO SIGNAL` 沒有出現。
- [ ] `B` `M` `T` 的長條有在動，畫面有反應。反應太弱就調高 **Gain**。
- [ ] Tempo 會變成 `LOCK`。若是不會鎖定的曲子，已確認可以用 `TAP`（`T`）對拍。

## 會場：畫面

- [ ] 已將主視窗移到輸出目的地（投影機 / 擷取卡）的顯示器。
- [ ] 必要時已用帶有 `?ui=hide` 的 URL 開啟（即使面板出現，也能用 `H` 隱藏）。
- [ ] 如果要疊在 OBS 上，已將背景設為透明（`?bg=transparent` 或 `B`）（[OBS](../obs/)）。
- [ ] 已在主視窗按 **`F`** 進入全螢幕（無法從 Deck 進入）。
- [ ] 已確認滑鼠停止後游標會消失（約 3 秒）。
- [ ] 已在主視窗按 **`S`** 開啟 Scene Deck，並移到手邊的螢幕。
- [ ] Deck 上沒有顯示「メイン窓が見つかりません」（找不到主視窗）、「AUDIO STOPPED」等警告。
- [ ] 主視窗只開了 1 個（在同一個瀏覽器開 2 個的話，Deck 的操作會傳到兩邊）。

## 會場：省電與通知

- [ ] 已關閉電腦的睡眠、螢幕關閉、螢幕保護程式。
- [ ] 已關閉作業系統與應用程式的通知（可能會顯示在全螢幕之上）。
- [ ] 筆電已接上電源（使用電池供電時，GPU 可能會被限制而變慢）。

## 演出中遇到問題時

| 症狀 | 先做這件事 |
| --- | --- |
| 畫面不再對聲音反應 | 在主視窗按 `H` 叫出面板，確認 `live` / `NO SIGNAL`。若已停止，按 **▶ Click to start audio**。 |
| 不喜歡目前的畫面 | 用 Deck 的 `1`～`8` 切到手牌，或用 `Q`（抽種子）/ `W`（細節）。 |
| 節拍跑掉了 | 用 `T` 重新 Tap，或用 `,` / `.` 修正倍率。用 `/` 回到自動。 |
| 不想讓關鍵畫面被動到 | 用 Deck 的 `L` 鎖定 30 秒（Deck 的一鍵切換也會停止）。 |
| 變得很卡 | 解析度會自動降低。若持續卡頓，就換成較輕的畫面（Deck 的其他欄位或其他種子）。 |
