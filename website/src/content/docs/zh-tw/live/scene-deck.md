title: Scene Deck（另開視窗切換）
description: 從另開視窗的操作台，用按鍵立即切換目前畫面的 8 個變化版本。
---

**Scene Deck** 是一個另開視窗的操作台，用起來就像 Resolume 的 Clip 清單。
它以主視窗目前顯示的 Patch 為基準（BASE），自動做出**Generator 組成相同、只有參數不同的 8 格**，按一個鍵就能一鍵切換。

- 設計上的用法是：主視窗 = 輸出到投影機 / 直播，Deck = 手邊的操作台。
- Deck 視窗不會啟動音訊輸入，也不會啟動繪圖引擎（不會有麥克風權限的對話框，也不會有持續的 GPU 負載）。
- 與主視窗的通訊，只透過同一個瀏覽器內的 `BroadcastChannel` 進行。無論線上版或本機版，都不需要準備中繼伺服器之類的東西。

## 開啟方式

用下列任一方式開啟。

- 在主視窗按 **`S`** 鍵
- 控制面板的 **Scene Deck** 按鈕
- 在 URL 加上 `?deck=1`（或 `?deck=true`）後開啟

用 `S` 或按鈕開啟的 Deck 只會有一個。如果已經開啟，只會把那個視窗拉到最前面，不會重新建立（手牌不會消失）。

:::caution
Deck 只能與**同一個瀏覽器（同一個設定檔）、同一個 URL 來源**所開啟的主視窗通訊。
另外，如果在同一個瀏覽器開了 2 個以上的主視窗，Deck 的操作會傳到兩邊。請只保留 1 個主視窗。
:::

## 現場的基本流程

1. 開啟主視窗，必要時加上 `?ui=hide`（隱藏面板）。
2. 在主視窗按 **`F`** 進入全螢幕。
   全螢幕受瀏覽器限制，**必須在主視窗操作**，無法從 Deck 進入。
3. 在主視窗按 **`S`** 開啟 Deck，並把 Deck 視窗移到手邊的螢幕。
4. 之後的操作（一鍵切換・抽種子・Hue・背景・Tap tempo・鎖定）都可以從 Deck 進行。

## 畫面的看法

| 位置 | 內容 |
| --- | --- |
| 標頭 | 按鍵操作的速查表，以及工具列（過渡預設組 `cut` / `default` / `slow`、`auto`、自動換場的間隔、`seq` / `rnd`、`R rebuild`、`G gacha`、手牌 `A`～`H`、`MIDI`、`learn`）。 |
| 手牌那一列 | `JSON copy`、`menu`（JSON paste・採用 seed・clear current）。→ [儲存手牌](../banks/) |
| MIDI 那一列 | MIDI 裝置與對應。→ [MIDI 控制器](../midi/) |
| 操作台那一列 | `Q gacha`、`W details`、Hue（固定切換・滑桿）、背景、`TAP` `÷2` `×2` `AUTO`、Timeline 鎖定。 |
| 狀態 | BPM、`AUDIO STOPPED`（主視窗的音訊輸入停止時）、自動換場與 MIDI 的狀態等。 |
| 格子 | 4 欄 × 2 列共 8 個欄位（`BASE`、`V1`～`V7`）。會顯示縮圖，以及標籤與變化內容（detail）。目前正在輸出的欄位會被強調。 |

如果 WebGL2 可用，縮圖會一張一張繪製出來（不可用的環境則維持顏色色塊）。
使用圖片（stamp）的 Patch，在縮圖中圖片會是透明的，所以看起來幾乎是空白的畫面。

## 一鍵切換

| 操作 | 動作 |
| --- | --- |
| `1`～`8` | 輸出該欄位（使用工具列上選取的過渡預設組） |
| `Shift` + `1`～`8` | 忽略預設組，以 `cut` 輸出 |
| `←` `→` `↑` `↓` | 移動游標（4 × 2） |
| `Enter` / `Space` | 輸出游標所在的欄位 |
| `X` | 依 `cut` → `default` → `slow` 的順序切換過渡預設組 |
| 點擊欄位 | 輸出該欄位 |

Bank（8 格）不會在每次一鍵切換時重新建立，所以隨時都能回到「剛才的 3 號」。

## 重新建立 Bank

| 操作 | 動作 |
| --- | --- |
| `R` / `R rebuild` | 以主視窗**目前顯示的 Patch** 當作 BASE，重新建立 8 格 |
| `G` / `G gacha` | BASE 維持不變，只重抽變化用的亂數（bankSeed） |

當主視窗的畫面變成 Bank 以外的內容（主視窗的 `R`、從 CLI 操作等），Deck 會顯示 **BASE CHANGED — R で再生成**（BASE 已改變 — 按 R 重新產生）。
可以繼續使用該 Bank，也可以按 `R` 從目前的畫面重新建立。

## 自動換場

以固定間隔自動輸出下一個欄位。

| 操作 | 動作 |
| --- | --- |
| `A` / `auto` 按鈕 | 自動換場 ON / OFF |
| `M` / 間隔按鈕 | 單位在「秒」⇄「小節」之間切換 |
| `-` / `=` | 減少 / 增加間隔（秒以 5 秒為單位，範圍 2～600 秒，預設 30 秒。小節以 1 小節為單位，範圍 1～256 小節，預設 8 小節） |
| `seq` / `rnd` 按鈕 | 依序換場 / 隨機換場（隨機會從目前欄位以外挑選） |

- 手動一鍵切換後，會從該位置接著自動換場（以秒計的計時器也會重置）。
- 以小節為單位時，只有在主視窗的節拍已鎖定（`LOCK` 或 `TAP`）才會前進。未鎖定時會顯示 **bars オートは tempo LOCK が必要です — 待機中**（小節自動模式需要節拍 LOCK — 等待中）並停下等待。
- 與主視窗的連線中斷期間會停止。

## 操作台（從 Deck 操作主視窗）

| 按鍵 | 按鈕 | 動作 |
| --- | --- | --- |
| `Q` | `Q gacha` | 重抽種子（相當於主視窗的 `R`） |
| `W` | `W details` | 只重抽細節（相當於主視窗的 `D`） |
| `B` | 背景按鈕 | 背景在黑色 ⇄ 透明之間切換 |
| `H` | Hue 固定按鈕 | Hue 在固定 ⇄ 循環之間切換。切換為固定時，會以目前的色相固定 |
| `[` / `]` | Hue 滑桿 | 固定 Hue 減少 15° / 增加 15° |
| `T` | `TAP` | Tap tempo |
| `,` / `.` | `÷2` / `×2` | 節拍減半 / 加倍 |
| `/` | `AUTO` | 節拍回到自動偵測 |
| `L` | 鎖定按鈕 | 將 Timeline 從現在起鎖定 30 秒 ⇄ 解除。鎖定期間，從 Deck 的一鍵切換也會被拒絕 |
| `F` | — | **Deck 視窗**的全螢幕（不是主視窗） |

:::note[日文鍵盤配置]
Deck 的按鍵不是依字元，而是依**按鍵的實體位置（以美式鍵盤配置為準）**判定。
在日文（JIS）配置下，`[` 位於 **`@`** 鍵的位置，`]` 位於 **`[`** 鍵的位置，`=` 位於 **`^`** 鍵的位置。
`1`～`8` 請使用鍵盤上排的數字鍵，而不是數字鍵台。
:::

## Deck 顯示的警告

| 顯示 | 意義與處理方式 |
| --- | --- |
| メイン窓が見つかりません（找不到主視窗） | 主視窗已關閉，或是在不同的瀏覽器 / 不同的 URL 開啟。 |
| メイン窓の Synth が動いていません（WebGL2 が必要です）（主視窗的 Synth 沒有運作，需要 WebGL2） | 主視窗的繪圖沒有運作。 |
| BASE CHANGED — R で再生成（BASE 已改變，按 R 重新產生） | 主視窗的畫面變成 Bank 以外的內容。 |
| STALE: generator 更新あり。R で live から取り直し（STALE：Generator 已更新，按 R 從即時畫面重新取得） | 已儲存的手牌因更新而與目前的 Generator 不相符（不會當掉，但所有變化版本都會等同於 BASE）。 |
| AUDIO STOPPED | 主視窗的音訊輸入已停止。請在主視窗按 **▶ Click to start audio**。 |
| timeline is locked for Ns | 因為處於鎖定狀態，一鍵切換被拒絕。 |
