## 音に反応しない

上から順に確認してください。

1. **パネル右上が `idle` になっていないか。** `idle` なら音声入力が止まっています。**▶ Click to start audio** を押します。
   ブラウザは、ページを開いた直後の自動開始を止めることがあります。そのときは一度クリックすれば始まります。
2. **エラーが出ていないか。** パネル上部に赤字で表示されます。

   | メッセージ | 意味と対処 |
   | --- | --- |
   | `Microphone permission was denied. …` | 音声入力が拒否されています。アドレスバーのサイト設定からマイクを許可して、ボタンを押し直します。 |
   | `No audio input device was found.` | 入力デバイスがありません。デバイスの接続を確認します。 |
   | `The selected audio device could not be opened (in use by another app?).` | ほかのアプリがデバイスを専有しているか、開けません。 |
   | `The selected audio device is unavailable. Pick a different one.` | 選んでいたデバイスが無くなりました。**Input device** で選び直します。 |
   | `This browser does not support audio capture.` | ブラウザが音声入力に対応していないか、安全な接続（HTTPS / localhost）で開いていません。 |

3. **`NO SIGNAL` が出ていないか。** 音声入力は動いているのに音が来ていません。**Input device** が正しいか、再生側の出力先が合っているか確認します。
   曲の音を拾うにはループバックが必要です（[デスクトップ音声](../live/obs/#デスクトップ音声に反応させる)）。
4. **レベルメーターは動くのに映像の反応が弱い。** **Gain** を上げます。
5. **OBS のブラウザソースで使っている。** ブラウザソースでは音声入力が取れないことがあります（[OBS](../live/obs/)）。

## 音が止まると映像もほとんど止まる

仕様です。無音のときは映像の時間が通常の約 5% の速さになり、拍の反応も止まります。音が入れば元に戻ります。

## 「WebGL2 が必要です」と出る

Seedshade は WebGL2 が使えないと描画できません。

- ブラウザの設定で、ハードウェアアクセラレーション（「グラフィック アクセラレーションが使用可能な場合は使用する」など）が有効になっているか確認します。
- Chrome / Edge なら `chrome://gpu` で WebGL2 が有効か確認できます。
- 仮想マシンやリモートデスクトップ越しでは使えないことがあります。

## 重い・カクつく

- 重いときは内部の描画解像度が自動で下がります（Timeline パネルの `quality` で確認できます）。それでも重いときは、軽い絵（別のシード、Deck の別スロット）に変えてください。
- ノート PC は電源につなぎ、省電力モードを切ります。
- ほかの重いタブやアプリを閉じます。
- キャンバスの解像度はデバイスピクセル比 1.5 までに制限しています。それより高い解像度のディスプレイでも負荷は増えません。窓（OBS ならソース）のサイズを小さくすると軽くなります。

## パネルが消えた / カーソルが消えた

- マウスを約 3 秒止めると、コントロールパネルとカーソルが自動で消えます。マウスを動かすと戻ります。
- `H` を押すと、コントロールパネルと Timeline パネルが隠れます。もう一度 `H` で戻ります。`?ui=hide` で開いた場合も同じです。

## 再読み込みすると見た目が戻ってしまう

保存されるのはパネルの **Look** に表示されているシードだけです。🧬（細部の引き直し）、Timeline の `Apply`、CLI から送ったシードや Patch、Deck のポン出しは保存されません。
残したい見た目は、Deck の手札（`A`〜`H`）に保存するか、[レシピ](../ai/recipe-set/) にしておきます。

## URL で指定した設定が次も残っている

URL パラメータで指定した値（`seed`、`hue`、`bg` など）は、そのまま保存されます。次に URL なしで開いても引き継がれるので、戻したいときはパネルで設定し直してください。

## LAN の別端末から開くと警告が出る

ローカル版（`pnpm dev`）は自己署名証明書の HTTPS で動いているため、ブラウザが警告を出します。「詳細設定」→「アクセスする」で進んでください。
マイクは安全な接続（HTTPS か localhost）でしか使えないので、HTTP には切り替えられません。

## Scene Deck

| 症状 | 対処 |
| --- | --- |
| `S` を押しても窓が開かない | ブラウザのポップアップブロックを確認し、このサイトのポップアップを許可します。 |
| 「メイン窓が見つかりません」 | メイン窓を同じブラウザ・同じ URL（オリジン）で開いてください。別のブラウザやプロファイル、ホスト版とローカル版の組み合わせでは通信できません。 |
| Deck からフルスクリーンにできない | フルスクリーンはメイン窓で `F` を押す必要があります。Deck の `F` は Deck 自身の窓をフルスクリーンにします。 |
| ポン出しが拒否される（`timeline is locked for …`） | Timeline がロック中です。Deck の `L` で解除できます。 |
| `[` `]` `=` が効かない | JIS 配列では `@` `[` `^` の位置のキーです（[ショートカット](../reference/shortcuts/)）。 |
| 2 つの画面が同時に切り替わる | 同じブラウザでメイン窓を 2 つ開いています。1 つにしてください。 |

## MIDI が効かない

- Deck の窓で **MIDI** ボタンを押しましたか？（メイン窓では MIDI を受けません）
- Chrome / Edge を使ってください。Safari は非対応、Firefox はアドオンが必要です。
- ほかのアプリ（DAW など）がデバイスを専有していないか確認します。
- nanoPAD2 がほかのアプリで普段のノートを出さなくなったら、USB を抜き差しします（[MIDI](../live/midi/)）。

## CLI / AI からつながらない

| エラー | 原因と対処 |
| --- | --- |
| `no synth connected` | メイン窓が中継につながっていません。URL に `?room=<id>`（ホスト版）か `?bridge=1`（ローカル版）が付いているか、room id が CLI と同じか確認します。`mirror=1` の窓だけでは応答しません。 |
| ホスト版で `?bridge=1` を付けても `no synth connected` | ローカル中継はホスト版からの接続を拒否します。ホスト版では `?room=` を使ってください（[ホスト版とローカル版](../reference/hosted-vs-local/)）。 |
| 接続できない（`ECONNREFUSED` など） | ローカル版なら `pnpm bridge` が起動していません。 |
| `timeout waiting for synth` | メイン窓のタブが背面に回って描画が止まっている可能性があります。メイン窓を前面に出します。 |
| `vj-gen: --url が指定されておらず…` | `vj-gen` / `vj-tweak` / `vj-recipe apply` は接続先の指定が必須です。`--url` か `VJ_URL` を指定します。 |
| `room` で作った URL が `seedshade.<account>.workers.dev` になっている | `--host seedshade.tainakanchu.com` を付けて作り直します。 |
| 存在しない Generator / パラメータのエラー | カタログのキャッシュが古い可能性があります。`--refresh-catalog` を付けます。 |

## 保存してあった Patch が適用できない

Generator は更新されるとバージョンが上がり、古いバージョンを指定した Patch は検証で落ちます（`generatorVersion` の不一致）。
長く使いたい見た目は Patch ではなく [レシピ](../ai/recipe-set/) で保存してください。Deck の手札は落ちずに `STALE` と表示されます（[手札の保存](../live/banks/#stale-と表示されたら)）。
