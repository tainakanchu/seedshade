本番の会場で慌てないための確認リストです。上から順に確認してください。

## 事前に（自宅で）

- [ ] 本番で使う PC とブラウザ（Chrome / Edge 推奨）で、Seedshade が描画できることを確認した（「WebGL2 が必要です」が出ない）。
- [ ] 本番と同じ解像度で、重すぎないことを確認した（Timeline パネルの `quality` が大きく下がり続けない）。
- [ ] 使いたいシードを控えた。必要なら Scene Deck の手札を `A`〜`H` に保存した（[手札の保存](../banks/)）。
- [ ] ロゴを stamp で使うなら、本番の PC・ブラウザで画像を登録しておいた（画像はブラウザごとに保存されます）。
- [ ] MIDI コントローラを使うなら、本番の PC で割り当てを確認した（[MIDI コントローラ](../midi/)）。
- [ ] ホスト版を使う場合、会場でインターネットにつながるか確認した。つながらない可能性があるなら、ローカル版（`pnpm build` → `pnpm preview` など）を用意した。

:::note
設定・手札・MIDI の割り当て・画像は、**ブラウザとオリジン（URL のドメイン）ごと** に保存されます。
自宅で `localhost` で準備したものは、ホスト版（`seedshade.tainakanchu.com`）では見えません。本番で開く URL と同じ URL で準備してください。
:::

## 会場で：音

- [ ] ミキサーのブース出力 / REC 出力などを、オーディオインターフェースのライン入力につないだ。
- [ ] **Input device** で正しい入力を選んだ。
- [ ] 音を出して、レベルメーターが目安の帯（-18〜-6 dBFS）に入る。`CLIP` が点かない。`NO SIGNAL` が出ない。
- [ ] `B` `M` `T` のバーが動き、映像が反応する。反応が弱ければ **Gain** を上げた。
- [ ] Tempo が `LOCK` になる。ならない曲なら `TAP`（`T`）で合わせられることを確認した。

## 会場で：映像

- [ ] メイン窓を出力先（プロジェクター / キャプチャ）のディスプレイに移した。
- [ ] 必要なら `?ui=hide` 付きの URL で開いた（パネルが出ていても `H` で隠せます）。
- [ ] OBS で重ねるなら、背景を透過（`?bg=transparent` か `B`）にした（[OBS](../obs/)）。
- [ ] メイン窓で **`F`** を押してフルスクリーンにした（Deck からは入れません）。
- [ ] マウスを止めてカーソルが消えることを確認した（約 3 秒）。
- [ ] メイン窓で **`S`** を押して Scene Deck を開き、手元の画面に移した。
- [ ] Deck に「メイン窓が見つかりません」「AUDIO STOPPED」などの警告が出ていない。
- [ ] メイン窓は 1 つだけ開いている（同じブラウザで 2 つ開くと Deck の操作が両方に届きます）。

## 会場で：省電力・通知

- [ ] PC のスリープ・画面オフ・スクリーンセーバーを切った。
- [ ] OS やアプリの通知を切った（フルスクリーンの上に出ることがあります）。
- [ ] ノート PC は電源につないだ（バッテリー駆動だと GPU が絞られて重くなることがあります）。

## 本番中に困ったら

| 症状 | まずやること |
| --- | --- |
| 映像が音に反応しなくなった | メイン窓のパネルを `H` で出し、`live` / `NO SIGNAL` を確認。止まっていたら **▶ Click to start audio**。 |
| 絵が気に入らない | Deck の `1`〜`8` で手札に逃げる、または `Q`（ガチャ）/ `W`（細部）。 |
| テンポがずれた | `T` でタップし直す、または `,` / `.` で倍率を直す。`/` で自動に戻す。 |
| 決めの画を触られたくない | Deck の `L` で 30 秒ロック（Deck からのポン出しも止まります）。 |
| 重くなった | 自動で解像度が下がります。続くようなら軽い絵（Deck の別スロットや別シード）に変える。 |
