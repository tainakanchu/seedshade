title: Scene Deck（別窓ポン出し）
description: 別窓の操作卓から、今の絵のバリエーション 8 面をキーで即座に切り替える。
---

**Scene Deck** は、Resolume のクリップ一覧のように使える別窓の操作卓です。
メイン窓に今出ている Patch を基準（BASE）に、**同じ Generator 構成のままパラメータだけ違う 8 面** を自動で作り、キー 1 つでポン出しできます。

- メイン窓 = プロジェクター / 配信への出力、Deck = 手元の操作卓、という運用を想定しています。
- Deck の窓では音声入力も描画エンジンも起動しません（マイク許可のダイアログも、常時の GPU 負荷もありません）。
- メイン窓との通信は同じブラウザ内の `BroadcastChannel` だけで行います。ホスト版でもローカル版でも、中継サーバーなどの準備は要りません。

## 開き方

次のどれかで開きます。

- メイン窓で **`S`** キー
- コントロールパネルの **Scene Deck** ボタン
- URL に `?deck=1`（または `?deck=true`）を付けて開く

`S` やボタンで開いた Deck は 1 つだけです。すでに開いていれば、その窓が手前に出るだけで作り直されません（手札が消えません）。

:::caution
Deck は **同じブラウザ（同じプロファイル）・同じ URL のオリジン** で開いているメイン窓としか通信できません。
また、メイン窓を同じブラウザで 2 つ以上開いていると、Deck の操作が両方の窓に届きます。メイン窓は 1 つにしてください。
:::

## 本番での基本の流れ

1. メイン窓を開き、必要なら `?ui=hide` を付けておく（パネル非表示）。
2. メイン窓で **`F`** を押してフルスクリーンにする。
   フルスクリーンはブラウザの制限で **メイン窓での操作が必要** です。Deck からは入れません。
3. メイン窓で **`S`** を押して Deck を開き、Deck の窓を手元の画面へ移す。
4. 以後の操作（ポン出し・シードのガチャ・Hue・背景・タップテンポ・ロック）は、すべて Deck から行えます。

## 画面の見かた

| 場所 | 内容 |
| --- | --- |
| ヘッダー | キー操作の早見表と、ツールバー（遷移プリセット `cut` / `default` / `slow`、`auto`、自動送りの間隔、`seq` / `rnd`、`R rebuild`、`G gacha`、手札 `A`〜`H`、`MIDI`、`learn`）。 |
| 手札の行 | `JSON copy`、`menu`（JSON paste・seed を採用・clear current）。→ [手札の保存](../banks/) |
| MIDI の行 | MIDI デバイスと割り当て。→ [MIDI コントローラ](../midi/) |
| 操作卓の行 | `Q gacha`、`W details`、Hue（固定トグル・スライダー）、背景、`TAP` `÷2` `×2` `AUTO`、Timeline ロック。 |
| ステータス | BPM、`AUDIO STOPPED`（メイン窓の音声入力が止まっているとき）、自動送りや MIDI の状態など。 |
| グリッド | 4 列 × 2 段の 8 スロット（`BASE`、`V1`〜`V7`）。サムネイルと、ラベル・変化の内容（detail）が表示されます。今出ているスロットが強調されます。 |

WebGL2 が使えればサムネイルが 1 枚ずつ描かれます（使えない環境では色チップのままです）。
画像（stamp）を使う Patch は、サムネイルでは画像が透明になるため、ほぼ空の絵に見えます。

## ポン出し

| 操作 | 動作 |
| --- | --- |
| `1`〜`8` | そのスロットを出す（ツールバーで選んでいる遷移プリセットで） |
| `Shift` + `1`〜`8` | プリセットを無視して `cut` で出す |
| `←` `→` `↑` `↓` | カーソルを動かす（4 × 2） |
| `Enter` / `Space` | カーソル位置のスロットを出す |
| `X` | 遷移プリセットを `cut` → `default` → `slow` の順に切り替える |
| スロットをクリック | そのスロットを出す |

バンク（8 面）はポン出しのたびに作り直されないので、「さっきの 3 番」にいつでも戻れます。

## バンクを作り直す

| 操作 | 動作 |
| --- | --- |
| `R` / `R rebuild` | メイン窓に **今出ている Patch** を BASE にして 8 面を作り直す |
| `G` / `G gacha` | BASE はそのまま、バリエーションの乱数（bankSeed）だけを引き直す |

メイン窓の絵がバンクの外のものに変わる（メイン窓の `R`、CLI からの操作など）と、Deck に **BASE CHANGED — R で再生成** と表示されます。
そのバンクで続けてもかまいませんし、`R` で今の絵から作り直してもかまいません。

## 自動送り

一定間隔で次のスロットを自動で出します。

| 操作 | 動作 |
| --- | --- |
| `A` / `auto` ボタン | 自動送り ON / OFF |
| `M` / 間隔ボタン | 単位を「秒」⇄「小節」で切り替える |
| `-` / `=` | 間隔を減らす / 増やす（秒は 5 秒刻みで 2〜600 秒、既定 30 秒。小節は 1 小節刻みで 1〜256 小節、既定 8 小節） |
| `seq` / `rnd` ボタン | 順番に送る / ランダムに送る（ランダムは今のスロット以外から選ぶ） |

- 手でポン出しすると、その位置から自動送りが続きます（秒のタイマーもリセットされます）。
- 小節単位はメイン窓のテンポがロックしているとき（`LOCK` または `TAP`）だけ進みます。外れていると **bars オートは tempo LOCK が必要です — 待機中** と表示されて待ちます。
- メイン窓との接続が切れている間は止まります。

## 操作卓（メイン窓の操作を Deck から）

| キー | ボタン | 動作 |
| --- | --- | --- |
| `Q` | `Q gacha` | シードを引き直す（メイン窓の `R` 相当） |
| `W` | `W details` | 細部だけ引き直す（メイン窓の `D` 相当） |
| `B` | 背景ボタン | 背景を黒 ⇄ 透過 |
| `H` | Hue 固定ボタン | Hue の固定 ⇄ サイクル。固定に入るときは今の色相で固定します |
| `[` / `]` | Hue スライダー | 固定 Hue を -15° / +15° |
| `T` | `TAP` | タップテンポ |
| `,` / `.` | `÷2` / `×2` | テンポを半分 / 倍 |
| `/` | `AUTO` | テンポを自動検出に戻す |
| `L` | ロックボタン | Timeline を今から 30 秒ロック ⇄ 解除。ロック中は Deck からのポン出しも拒否されます |
| `F` | — | **Deck の窓** のフルスクリーン（メイン窓ではありません） |

:::note[日本語配列のキーボード]
Deck のキーは文字ではなく **キーの物理的な位置（US 配列基準）** で判定しています。
日本語（JIS）配列では、`[` は **`@`** キー、`]` は **`[`** キー、`=` は **`^`** キーの位置になります。
`1`〜`8` はテンキーではなく、キーボード上段の数字キーを使ってください。
:::

## Deck に出る警告

| 表示 | 意味と対処 |
| --- | --- |
| メイン窓が見つかりません | メイン窓が閉じている、または別のブラウザ / 別の URL で開いています。 |
| メイン窓の Synth が動いていません（WebGL2 が必要です） | メイン窓で描画が動いていません。 |
| BASE CHANGED — R で再生成 | メイン窓の絵がバンクの外のものに変わりました。 |
| STALE: generator 更新あり。R で live から取り直し | 保存してあった手札が、アップデートで今の Generator と合わなくなりました（落ちはしませんが、バリエーションが全部 BASE 相当になります）。 |
| AUDIO STOPPED | メイン窓の音声入力が止まっています。メイン窓で **▶ Click to start audio** を押してください。 |
| timeline is locked for Ns | ロック中なのでポン出しが拒否されました。 |
