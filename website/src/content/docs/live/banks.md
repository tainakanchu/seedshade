---
title: 手札（バンク）の保存
description: Scene Deck の 8 面を A〜H のスロットに保存して呼び出す、JSON で別の PC に持ち出す。
---

Scene Deck の 8 面（BASE + V1〜V7）を「手札」と呼んでいます。手札は自動で保存されるほか、`A`〜`H` の 8 つのスロットに名前を付けて取っておけます。

## 何が保存されるか

保存されるのは **基準の Patch（BASE）と、バリエーションの乱数（bankSeed）** だけです。
8 面そのものは保存せず、同じ入力から毎回同じ 8 面を作り直します。あわせて、遷移プリセット・自動送りの設定・カーソル位置・保存時のメイン窓のシードも保存されます。

保存先はブラウザの `localStorage`（キー `seedshade-deck-banks-v1`）です。

## 自動保存（クラッシュ対策）

- 手札・遷移プリセット・自動送り・カーソルが変わるたびに、約 0.5 秒後に自動保存されます。
- Deck を開き直すと、保存してあった手札が **メイン窓を待たずに** すぐ復元されます。
- 一度も保存されていなければ、メイン窓の今の絵から手札を作ります。

## A〜H スロット

ツールバーの `A`〜`H` の小さなボタンを使います（空のスロットは薄く表示されます）。

| 操作 | 動作 |
| --- | --- |
| `Shift` + クリック | 今の手札をそのスロットに保存（**上書き確認はありません**） |
| `Shift` + `S` | 次の空きスロットに保存（空きが無ければ `A` に上書き） |
| クリック | そのスロットの手札を呼び出す |
| 右クリック / 長押し | スロットの名前を編集（Enter で確定、Esc で取り消し） |

:::caution[呼び出しても絵はすぐには変わりません]
スロットを呼び出すと、Deck の 8 面が差し替わるだけです。メイン窓の絵は、パッド（`1`〜`8` など）を押すまで変わりません。
保存時のメイン窓のシードも自動では送りません。シードも戻したいときは、`menu` の **seed を採用** を押してください（メイン窓のシード設定と絵の両方が切り替わります）。
:::

## JSON で持ち出す

別の PC やブラウザに手札を持っていくときに使います。

1. `JSON copy` を押すと、今の手札がクリップボードにコピーされます（`copied` と表示）。
2. 持っていく先の Deck で `menu` を開き、テキスト欄に貼り付けて `JSON paste` を押します。

:::note[画像は持ち出せません]
Patch には画像そのものではなく、画像の参照（ハッシュ）だけが入っています。画像のデータはブラウザの IndexedDB（`seedshade-images`）にあります。
JSON だけを別の PC に持っていくと、stamp の画像は透明になります。先方でも同じ画像を Timeline パネルから登録してください（同じファイルなら同じハッシュになります）。
:::

## STALE と表示されたら

Seedshade のアップデートで Generator が更新されると、保存してあった BASE が今のカタログで検証を通らなくなることがあります。
そのときは **STALE: generator 更新あり。R で live から取り直し** と表示されます。

- Deck は落ちませんが、バリエーションが全部 BASE 相当になります。
- `R` を押して、メイン窓の今の絵から手札を作り直してください。

## 消去する

`menu` の `clear current` → `confirm clear current` の 2 段階で、自動保存の手札（current）を消せます。
次に Deck を開くと、メイン窓の今の絵から作り直されます。`A`〜`H` のスロットは消えません。
