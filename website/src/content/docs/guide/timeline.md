---
title: Timeline パネル
description: 演出イベントの予約、Patch の直接編集、画像のスタンプ、演出の記録と再生。
---

画面右上の **Timeline パネル** は、Semantic Synth を細かく操作するための上級者向けパネルです。
CLI や AI から操縦するときに使う操作（[vj-ctl](../../ai/vj-ctl/)）と同じものを、画面から手で叩けます。

上から次のセクションが並んでいます。パネル右上の `▾ close` でたたみ、`H` で（コントロールパネルと一緒に）隠せます。

## State（現在の状態）

| 表示 | 内容 |
| --- | --- |
| `idle` / `transitioning` | 次の見た目へ遷移中かどうか。 |
| `seed` | 今出ている Patch のシード。 |
| `operators` | 今の Patch を構成する Generator を順に表示（例: `spectrumBars › gamma › sodium`）。 |
| `quality` | 内部描画解像度の倍率（1.00 = 等倍。重いと自動で下がります）。 |
| `tempo` | `locked` / `free` とカウント中の小節番号（`bar N`）。 |

`synth is not running (WebGL2 required)` と出ている場合は、描画が動いていません（[トラブルシューティング](../../troubleshooting/)）。

## Patch（現在の Patch を直接編集する）

今出ている Patch の JSON が表示されています。

1. テキスト欄を直接書き換えます（書き換えると `edited` と表示され、ライブの Patch には追従しなくなります）。
2. **Apply** を押すと検証にかけられ、通れば新しい Patch へ遷移します。
3. 検証に落ちると、理由が下に箇条書きで表示されます。
4. **Reload** で編集を捨てて、今のライブの Patch を読み込み直します。

Patch の制約（Generator の個数・順番・パラメータの範囲など）は [Semantic Synth のしくみ](../semantic-synth/) と、AI 向けの [vj-director スキル](../../ai/claude-code/) に詳しく書かれています。

## Events（予約イベントの一覧）

Timeline に登録されているイベントが、発火する順に並びます。

| 表示 | 意味 |
| --- | --- |
| `@12.0s` | 12 秒の時点で発火（シーン時計の秒数） |
| `@bar 16` | 16 小節目で発火 |
| `@ext:drop` | `drop` という名前で手動発火されるまで待つ（external） |
| `locked` | 編集できないイベント |
| `fired` | 発火済み |

`✕` でイベントを削除します。

## Add event（イベントを予約する）

「N 秒後 / N 小節後にこのシードへ切り替える」を予約します。

1. 1 段目で基準を選びます。
   - `+sec` … 今から N 秒後
   - `+bars` … 今から N 小節後（**テンポがロックしているときだけ発火** します）
   - `external` … 名前（external id）を付けて待機。下の **External** で `Fire` するまで発火しません
2. 数値（または external id）を入れます。
3. 2 段目にシードを入れます。空欄ならランダムなシードになります。
4. 遷移の速さを選びます。

   | プリセット | 内容 |
   | --- | --- |
   | `default` | 標準（色 1.2 秒、構成の入れ替え 2 秒など） |
   | `slow` | `default` の 2 倍の時間をかけて溶ける |
   | `cut` | 約 0.12 秒で切り替わる |

5. **Add** を押します。

## Locked until（ロック）

数値を入れて **Set** すると、その時刻（シーン時計の秒数）までを「ロック」します。
ロック中は次の操作が拒否されます。

- その時刻より前に発火するイベントの編集・削除
- Scene Deck からのポン出し

:::caution
ここに入れる値は「今から何秒」ではなく **シーン時計の絶対秒数** です。`0` を入れると解除になります。
今から N 秒ロックしたいときは、Scene Deck の `L`（30 秒ロック ⇄ 解除）か、CLI の `vj-ctl lock <秒>`（相対指定）を使う方が簡単です。

また、ロックは Timeline と Scene Deck のための保護で、メイン窓の `R` / `D`、Patch の `Apply`、CLI の `vj-ctl seed` / `patch` は止めません。
:::

## External（手動発火）

external id を入れて **Fire** を押すと、その id で待機している `external` イベントを発火します（同じ id のイベントが複数あれば全部）。
「ドロップの瞬間にこの絵」を予約しておいて、タイミングだけ手で決めたいときに使います。

## Images（画像をスタンプする）

ロゴなどの画像を映像に入れられます。

1. 画像（PNG / JPG / WebP / GIF / SVG / AVIF）を、メイン窓のどこかにドラッグ & ドロップします。ファイル選択ボタンからでも登録できます。
2. 一覧に出た画像の **stamp に使う** を押します。
3. 今の Patch に `stamp` Generator が入り（すでにあれば画像だけ差し替え）、その画像が描かれます。

- 登録した画像はブラウザの IndexedDB（`seedshade-images`）に保存され、次回も一覧に残ります。
- Source は 1 Patch に 2 つまでなので、すでに 2 つある場合は最後の Source が外れて `stamp` に置き換わります。
- `stamp` はシードのガチャでは選ばれません。シードを引き直すと画像は消えるので、もう一度 **stamp に使う** を押してください。

## Recording（演出の記録と再生）

1. **● Record** で記録を始めます。以降の Timeline 操作（イベントの追加・削除など）と発火が記録されます。
2. **■ Stop & save** で止めると、`performance-<数字>.json` がダウンロードされます。
3. 右のファイル選択で JSON を読み込むと、記録した Timeline が復元され、記録開始時の Patch に戻ってから再生されます。

:::note
記録される時刻はシーン時計（ページを開いてからの経過時間）の秒数です。
すでにその時刻を過ぎたページで読み込むと、過去のイベントがまとめて発火することがあります。
きっちり再現したいときは、ページを開き直してから読み込んでください。
:::
