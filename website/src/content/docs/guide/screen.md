メイン窓には、全画面のビジュアルの上に 2 枚のパネルが重なっています。

- **左上: コントロールパネル**（`SEEDSHADE`） — 音声入力・テンポ・シード・色・背景などの基本操作
- **右上: Timeline パネル** — 予約イベント・Patch の直接編集・画像・録画などの上級操作（[Timeline パネル](../timeline/)）

## パネルの表示 / 非表示

| 状態 | 操作 | 内容 |
| --- | --- | --- |
| 隠す / 出す | **`H`** | コントロールパネルと Timeline パネルの **両方** を隠します。もう一度押すと戻ります。 |
| 最初から隠す | URL に `?ui=hide` | OBS や本番出力向け。`H` で出せます。 |
| 自動フェード | マウスを約 3 秒止める | **コントロールパネルだけ** が透明になり、マウスカーソルも消えます。マウスを動かす・クリックする・キーを押すと戻ります。 |
| Timeline をたたむ | Timeline の `▾ close` | 見出しだけの小さな表示になります。`▸ open` で戻ります。 |

:::caution
Timeline パネルは自動フェードしません。本番の出力画面では **`H`** か `?ui=hide` で隠してください。
:::

## コントロールパネルの項目

上から順に並んでいます。

| 項目 | 内容 |
| --- | --- |
| ヘッダー | `live`（音声入力が動作中）/ `idle`（停止中）。 |
| **▶ Click to start audio** / **■ Stop audio** | 音声入力の開始 / 停止。起動直後に自動で始まらなかったときはここを押します。 |
| レベルメーター | Gain をかける前の入力レベル（dBFS）。-60〜0 の目盛りと、目安の帯（-18〜-6）、ピークホールド線があります。 |
| `CLIP` | 入力が飽和したときに約 1.5 秒点灯します。 |
| ビートドット | 拍を検出するたびに光ります。 |
| `NO SIGNAL` | 音声入力が動いているのに、ほぼ無音（約 -60 dBFS 未満）が 3 秒続くと表示されます。 |
| `B` / `M` / `T` | 低域・中域・高域のレベル（Gain 適用後）。映像はこの値で動きます。 |
| **Tempo** | 現在の BPM、状態チップ（`LOCK` / `SEARCH…` / `TAP`）、小節内の拍位置（4 つの点、左端が 1 拍目）、`TAP` `×2` `÷2` `AUTO` ボタン。→ [テンポ同期](../tempo/) |
| **Look** | 現在のシード、シード入力欄、🎲（シードを引き直す）、🧬（細部だけ引き直す）。→ [シード](../seed/) |
| **Input device** | 音声入力デバイスの選択。動作中に変えると即座に切り替わります。 |
| **Gain** | 解析に使う信号の倍率（0.5〜4、既定 1.5）。映像の反応の強さが変わります。 |
| **Hue** | `Cycle`（色相がゆっくり回り続ける）/ `Fixed`（スライダーで 0〜360° に固定）。 |
| **Background** | `Black`（黒背景）/ `Transparent`（透過背景）。透過は OBS で重ねるとき用です。→ [OBS](../../live/obs/) |
| **🎲 Auto-gacha** | `On` にすると、指定した小節数ごとにシードを自動で引き直します（1〜512 小節、既定 32）。→ [テンポ同期](../tempo/#n-小節ごとの自動ガチャ) |
| **Scene Deck** | 操作卓の別窓を開きます。→ [Scene Deck](../../live/scene-deck/) |
| **⛶ Fullscreen** | フルスクリーンの切り替え。 |

パネルの一番下には、ショートカットの早見表が表示されています。

## メイン窓のキーボードショートカット

テキスト入力欄・選択欄にフォーカスがあるときと、`Ctrl` / `Alt` / `⌘` を押しながらのときは反応しません。

| キー | 動作 |
| --- | --- |
| `H` | パネル（コントロール + Timeline）の表示 / 非表示 |
| `F` | フルスクリーン切り替え |
| `B` | 背景を黒 ⇄ 透過 |
| `R` | シードを引き直す（🎲 と同じ） |
| `D` | 同じ構成のまま細部だけ引き直す（🧬 と同じ） |
| `S` | Scene Deck の窓を開く（開いていれば手前に出す） |
| `T` | タップテンポ |

Scene Deck の窓には別のショートカットがあります。一覧は [キーボードショートカット](../../reference/shortcuts/) を参照してください。

## 画面にファイルをドロップする

画像ファイル（PNG / JPG / WebP / GIF / SVG / AVIF）をメイン窓のどこかにドラッグ & ドロップすると、Timeline パネルの **Images** に登録されます。
登録した画像を映像に入れる方法は [Timeline パネル](../timeline/#images画像をスタンプする) を参照してください。
