Seedshade が描く映像は、すべて **Semantic Synth** という 1 つのエンジンから出ています。
固定の描画プログラムを切り替えるのではなく、**シードから GLSL シェーダを毎回組み立てて** 描きます。
ここでは、操作する上で知っておくと役に立つしくみを説明します。

## Patch と Generator

1 つの見た目は **VisualPatch**（以下 Patch）という JSON で表現されます。
Patch は、部品である **Generator** を何個か上から順に重ねたものです。Generator は 4 つのカテゴリに分かれています。

| カテゴリ | 役割 | 1 Patch に入る数 | 種類 |
| --- | --- | --- | --- |
| **Source** | 絵の元になる模様・図形を描く | 1〜2 | 60 |
| **Field** | 座標を曲げる・流す（歪み、うねり、レンズなど） | 0〜2 | 17 |
| **Modifier** | 色や階調を加工する（しきい値、ガンマなど） | 1〜3 | 23 |
| **Material** | 最後に質感をのせる（光、ハイライト、素材感など） | 1 | 27 |

合計 **127 種類** です。重ねる順番は必ず Source → Field → Modifier → Material です。
シードを引くと、この範囲で個数と種類が決まり、それぞれのパラメータ・配色（palette）・構図（composition: 対称数・スケール・速さ）も決まります。

:::tip
今どの Generator が使われているかは、Timeline パネルの **State** → `operators` に表示されています（例: `qilouShutter › humidityLens › gamma › sodium`）。
:::

全 Generator の実際の見た目を一覧したいときは、開発者向けの `vj:preview --contact-sheet` で 1 枚の画像に焼けます（[vj:preview / vj:validate](../../dev/preview-validate/)）。

## 音が映像を動かすしくみ

音の解析結果（低域 `bass`・中域 `mid`・高域 `treble`・音量 `level`・拍 `beat` や小節の位相など）は、次の 3 つの経路で映像に効きます。

### 1. 時間の進む速さ

映像の時間は一定の速さでは進まず、**音の大きさで進む速さが変わります**。

- **無音ではほぼ止まります**（通常の約 5% の速さ）。
- 音が入ると素早く立ち上がり、止まったあとは 1 秒弱かけてゆっくり減速します。
- BPM がロックしていれば全体の速さがテンポに合わせて 0.7〜1.25 倍に変わり、拍の頭で少し前に押されます。

### 2. 変調（Patch の中の結線）

Patch には「どの音の値で、どのパラメータを動かすか」という結線（route）が入っています。
シードから自動で作られる結線は、**音が大きいほど「見える・動く」方向にしか効かない** ように作られています。
大音量が続くクラブで画面が暗くなり続ける、という事故は起きない設計です。

### 3. 拍で起きること

画面全体には、拍に合わせた反応（**オーディオ・リアクション**）がかかります。
Patch ごとに、座標に効くもの 1〜2 種類と色に効くもの 1 種類が、Generator の構成から決まります。
シードを引き直して構成が変われば、拍で起きることも変わります。🧬（細部だけ引き直す）では変わりません。

| 座標に効く | 内容 |
| --- | --- |
| `punchZoom` | 拍の頭で画面が寄る |
| `sliceShift` | 横帯ごとに水平にずれる（テープが飛ぶようなグリッチ） |
| `blockCrush` | 拍でマクロブロックに潰れる |
| `jitter` | 拍で画が飛び、高域で細かく震える |
| `spinKick` | 拍で回転が蹴られる |
| `waveTear` | 走査線が横に裂けて流れる |
| `mirrorSnap` | 拍で鏡像に畳まれる |
| `swellDrift` | うねりが横に流れる（海面が寄せては返す） |
| `setSurge` | 長周期のうねりでゆっくり寄って持ち上がる |

| 色に効く | 内容 |
| --- | --- |
| `rgbSplit` | 拍で R/B が横にずれる（色収差グリッチ） |
| `echoGhost` | 拍で少し縮んだ残像が背後に重なる |
| `hueSlam` | 拍で色相が飛ぶ |
| `posterCrush` | 拍で階調が段々に潰れる（ビットクラッシュ） |
| `invertFlash` | 強い拍だけ一瞬ネガになる |
| `scanGlow` | 走査バンドが流れ、拍で光る |
| `channelRoll` | 強い拍で RGB が入れ替わる |
| `crestGlow` | うねりの峰がゆっくり通り抜けて明るむ |

- **無音では完全に効かなくなり**、Patch そのままの見た目に戻ります。
- 今の Patch に載っているリアクションは、CLI の `vj-ctl state` の `reactions` で確認できます（[vj-ctl](../../ai/vj-ctl/)）。

`swellDrift` / `setSurge` / `crestGlow` は拍ではなく、音のエネルギーから作った「海のうねり」のような長い周期の時計で動きます。ドロップのあとに遅れてうねりが来て、ブレイク後も余韻が残ります。

## 旧シーンの見た目を引き継いだ Generator

以前の Seedshade には、スペクトラム・バーやオシロスコープなどの固定シーンがありました。
今はそれらが Semantic Synth の Generator（すべて Source）として移植され、ふつうのガチャの候補に入っています。

| Generator | 見た目 | 音の読み方 |
| --- | --- | --- |
| `spectrumBars` | スペクトラム・バー（ピークホールド付き） | スペクトラム |
| `spectrumRadial` | 円形スペクトラム | スペクトラム |
| `oscilloscope` | オシロスコープ（波形） | 波形 |
| `lissajousScope` | X-Y リサージュ | 波形 |
| `beatRings` | 拍で広がるリング（円 / 多角形 / 弧） | 通常の音の値 |
| `particleField` | パーティクル（上昇 / 軌道 / 雨 / 星空） | 通常の音の値 |
| `inkMarble` | 墨流しマーブル（旧 Fluid） | 通常の音の値 |
| `smokeFog` | 煙 | 通常の音の値 |
| `auroraCurtain` | オーロラ | 通常の音の値 |
| `lavaBlobs` | ラバランプ（旧 Lava） | 通常の音の値 |

「スペクトラム」「波形」を読む Generator には、128 バンドの対数スペクトラム（平滑化・ピークホールド付き）と 256 サンプルの波形が毎フレーム送られます。
これらを使わない Patch には一切送られないので、負荷は増えません。無音のときはスペクトラムが 0、波形は平らになります。

:::note
Scene Deck のサムネイルや、テスト / プレビュー用の描画では、時間に依存しない固定の合成信号を使って描きます。
そのため、スペクトラム系の Generator はサムネイルでは実際の音とは違う形で表示されます。
:::

CLI の `vj:gen` では「スペクトラム」「オシロ」「リサージュ」「オーロラ」「煙」「パーティクル」「リング」「マーブル」といった語でこれらを呼び出せます（[vj:gen / vj:tweak](../../ai/gen-tweak/)）。

## 画像（スタンプ）

画像を貼り込む `stamp` という Generator もあります。これは **シードのガチャでは選ばれません**（イベントロゴなどが勝手に出たり消えたりしないようにするため）。
画像を使うときは自分で入れます。→ [Timeline パネルの Images](../timeline/#images画像をスタンプする)

## 負荷と画質

- キャンバスの解像度は、デバイスピクセル比（DPR）を最大 1.5 に制限しています（高解像度ディスプレイでの過負荷を避けるため）。
- フレーム時間を監視していて、重いときは **内部の描画解像度を段階的に自動で下げ**、余裕が戻れば元に戻します。現在の倍率は Timeline パネルの **State** → `quality` に表示されます（1.00 が等倍）。
- WebGL のコンテキストが失われても自動で復帰します。
- 背景を透過にすると、描画結果もアルファ付きのまま出力されます（OBS で重ねられます）。
