いちばん早いのは、公開中のアプリ（ホスト版）を開くことです。インストールは要りません。

<Steps>

1. **アプリを開く**

   Chrome か Edge で [https://seedshade.tainakanchu.com](https://seedshade.tainakanchu.com) を開きます。
   左上に `SEEDSHADE` と書かれたコントロールパネル、右上に `Timeline` パネルが出ます。

   「WebGL2 が必要です」と表示された場合は、そのブラウザ / PC では描画できません。
   [トラブルシューティング](../../troubleshooting/#webgl2-が必要ですと出る) を見てください。

2. **マイク（音声入力）を許可する**

   開いた直後に、ブラウザが音声入力の使用許可を求めてきます。**許可** を選んでください。

   許可しても反応しない、またはダイアログが出ない場合は、パネル上部の
   **▶ Click to start audio** ボタンを 1 回クリックします。
   パネル右上の表示が `idle` から `live` に変わり、ボタンが **■ Stop audio** になれば音声入力が動いています。

3. **入力デバイスを選ぶ**

   パネルの **Input device** から、使う入力を選びます（既定は `System default`）。
   デバイス名は許可したあとで表示されます。動作中に切り替えると、そのまま新しいデバイスで取り込み直します。

   曲そのものに反応させたい場合は、マイクではなく **ループバック**（再生中の音を入力として拾う仮想デバイス）を選びます。
   設定方法は [OBS・透過・デスクトップ音声](../../live/obs/#デスクトップ音声に反応させる) を参照してください。

4. **レベルを合わせる**

   音を鳴らして、パネルのレベルメーターと `B` `M` `T`（低域・中域・高域）のバーが動くことを確認します。
   レベルメーターは **入力そのもの（Gain をかける前）** の大きさを dBFS で表示しています。
   メーター上の明るい帯（-18〜-6 dBFS）に収まるのが目安です。

   - 何も動かず `NO SIGNAL` と出る（約 -60 dBFS 未満が 3 秒続くと表示） → 入力デバイスが違うか、音が来ていません。
   - `CLIP` が点く → 入力が飽和しています。再生側やオーディオインターフェースの音量を下げます（Gain を下げても消えません）。
   - 映像の反応が弱い / 強すぎる → **Gain** スライダー（0.5〜4 倍、既定 1.5 倍）で調整します。
     Gain は解析に使う信号だけに効くので、`B` `M` `T` のバーは変わりますが、レベルメーターは変わりません。

5. **シードを引く（look gacha）**

   パネルの **Look** 行にある 🎲 ボタン、またはキーボードの **`R`** を押します。
   `neon-tiger-042` のようなランダムなシードが生成され、まったく別の見た目へクロスフェードで切り替わります。
   気に入った見た目が出たら、表示されているシード文字列を控えておけば、あとで同じ絵を再現できます。

6. **フルスクリーンにして、パネルを隠す**

   **`F`** でフルスクリーン、**`H`** でパネル（コントロールパネルと Timeline パネルの両方）を隠します。
   もう一度 `H` を押すと戻ります。

</Steps>

<Aside type="tip" title="ここまでできたら">
  - 同じ「形」のまま色や細部だけ変えたいときは 🧬 ボタン / **`D`**（[シード](../seed/)）
  - 曲に合わせて自動でシードを引き直すなら **🎲 Auto-gacha**（[テンポ同期](../tempo/)）
  - 本番で 8 面のバリエーションをポン出しするなら **`S`** で [Scene Deck](../../live/scene-deck/)
</Aside>

## 設定は自動で保存されます

ゲイン・Hue・背景・Auto-gacha・入力デバイス・シードは、ブラウザ（`localStorage`）に自動保存され、次に開いたときもそのままです。
起動時の設定を URL で指定することもできます（[URL パラメータ](../../reference/url-params/)）。

<Aside type="note">
  保存先はブラウザとオリジン（URL のドメイン）ごとに別です。ホスト版と、手元で起動したローカル版（`localhost`）の設定は共有されません。
</Aside>

## 手元で起動したい場合

開発中のコードを試したい、またはローカルの中継（`pnpm bridge`）を使いたい場合は、リポジトリを clone して起動します。

<Tabs>
<TabItem label="ローカルで起動">

```bash
git clone https://github.com/tainakanchu/seedshade.git
cd seedshade
pnpm install
pnpm dev
```

表示された URL（通常 `https://localhost:5173/`）を開きます。開発サーバーは自己署名証明書の **HTTPS** で起動するため、
最初にブラウザの警告が出ます。「詳細設定」→「アクセスする」で進んでください。

</TabItem>
<TabItem label="ホスト版との違い">

描画・パネル・Timeline・Scene Deck・MIDI はどちらでも同じように使えます。
違うのは CLI / AI から操縦するときの接続方法です。詳しくは [ホスト版とローカル版](../../reference/hosted-vs-local/) を参照してください。

</TabItem>
</Tabs>
