Seedshade の見た目は **シード（文字列）** で決まります。
シードを変えると、Generator の組み合わせ・パラメータ・配色・構図・音への反応のしかたまで一括で変わるので、ガチャを引くように絵が入れ替わります。これを **look gacha** と呼んでいます。

## 基本

- 同じシードからは **必ず同じ見た目** が再現されます。気に入った絵が出たら、パネルの **Look** に表示されているシード文字列を控えておきましょう。
- シードの文字列の「意味」は見ていません。`humid-night-market` と `take-3` は、ただの別の乱数の種です。名前は自分が思い出すための索引だと考えてください。
- 切り替えはハードカットではなく、クロスフェードで滑らかに遷移します。

## 🎲 と 🧬 の違い

| 操作 | キー | 何が変わるか |
| --- | --- | --- |
| 🎲 シードを引き直す | `R` | **すべて**。Generator の構成（どの部品をどう重ねるか）から変わります。新しいシードはパネルの Look に反映され、保存されます。 |
| 🧬 細部だけ引き直す | `D` | Generator の構成は **そのまま**、パラメータ・音による変調の結線・配色・構図だけを新しい乱数で引き直します。 |

🧬 は「形は気に入っているけれど、色や動きを変えたい」ときに使います。
構成が変わらないので、拍で起きるグリッチの種類（[オーディオ・リアクション](../semantic-synth/#3-拍で起きること)）も変わりません。

:::note
🧬 で引き直した結果はシードとしては保存されません（パネルの Look の表示も変わりません）。
ページを再読み込みすると、Look に表示されているシードの見た目に戻ります。
:::

## シードを手で入力する

1. **Look** 行の入力欄にシード文字列を入力します（最大 64 文字）。
2. **Enter** を押すか、入力欄の外をクリックすると適用されます（1 文字ごとには反映されません）。

空欄で確定した場合は元のシードに戻ります。
URL の `?seed=…` で起動時のシードを指定することもできます（[URL パラメータ](../../reference/url-params/)）。

## 自動で引き直す

**🎲 Auto-gacha** を `On` にすると、指定した小節数ごとに自動でシードを引き直します。
テンポがロックされている（またはタップで設定されている）間だけ進みます。→ [テンポ同期](../tempo/#n-小節ごとの自動ガチャ)

## 狙った雰囲気を出したいとき

シードは完全にランダムなので、「湿った夜っぽい絵」を狙って出すことはできません。狙いがあるときは次の方法があります。

| 方法 | 内容 |
| --- | --- |
| Scene Deck | 今の絵を基準に、同じ構成でパラメータ違いの 8 面を作ってポン出しできます。→ [Scene Deck](../../live/scene-deck/) |
| `vj:gen`（CLI） | 「雲 静寂 青」のようなムード語から Patch を生成します。→ [vj:gen / vj:tweak](../../ai/gen-tweak/) |
| レシピ（CLI） | 「ムード語 + シード + 手直し」を JSON で保存しておき、いつでも作り直せます。リポジトリの `recipes/` に 30 本以上の例があります。→ [vj:recipe / vj:set](../../ai/recipe-set/) |
| Patch を直接書く | Timeline パネルの **Patch** 欄で JSON を編集して `Apply`。→ [Timeline パネル](../timeline/#patch現在の-patch-を直接編集する) |
