---
title: テンポ同期（BPM）
description: BPM の自動検出、タップテンポ、×2 / ÷2、N 小節ごとの自動ガチャ。
---

Seedshade は入力音から BPM をリアルタイムに推定し、拍と小節のグリッドを作ります。
このグリッドは、拍で起きるグリッチ、映像の速さ、Auto-gacha、Timeline の小節指定イベント、Scene Deck の小節単位の自動送りに使われます。

## Tempo セクションの見かた

コントロールパネルの **Tempo** に次が表示されます。

| 表示 | 意味 |
| --- | --- |
| BPM 値 | 現在の BPM。未検出のときは `—`。 |
| `SEARCH…` | 自動検出中（まだロックしていない）。 |
| `LOCK` | 自動検出でテンポが確定した状態。 |
| `TAP` | タップで手動設定したテンポで動いている状態。 |
| 4 つの点 | 小節内の拍位置。左端（1 拍目）が強調表示です。 |

## 自動検出

- 低域（キック）の立ち上がりから自己相関で BPM を推定します。**四つ打ちのようにキックが規則的な曲に強い** です。
- 解析には最低 3 秒ぶんの音が必要で、ロックまでは数秒かかります。
- 推定する範囲は 60〜200 BPM で、結果は 70〜180 BPM の範囲に収まるよう倍 / 半分に折りたたまれます。
  ハーフタイム / ダブルタイムの曲で意図と違う倍率になったら、`×2` / `÷2` で直します。
- 一度ロックすると、グリッドは **自走** します。ブレイク中（無音区間）でも拍を刻み続け、曲が戻ると位相をゆるやかに合わせ直します。

## ボタンとキー

| ボタン | キー | 動作 |
| --- | --- | --- |
| `TAP` | `T` | 曲に合わせて 2 回以上叩くと、その間隔から BPM を設定します。間隔は直近 6 回ぶんの中央値を使い、2 秒以上あくと数え直しになります。音声が止まっていてもグリッドは回ります。 |
| `×2` | — | テンポを倍にします。 |
| `÷2` | — | テンポを半分にします。 |
| `AUTO` | — | 自動検出に戻します（倍率も 1 倍に戻ります）。 |

`×2` / `÷2` の倍率は 0.25〜4 倍の範囲です。Scene Deck の窓からは `,`（÷2）`.`（×2）`/`（AUTO）`T`（タップ）でも操作できます。

:::tip
キックがはっきりしない曲（アンビエント、ブレイクビーツ、生演奏など）では、自動検出が安定しないことがあります。
その場合は `TAP` で手動設定するのが確実です。
:::

## N 小節ごとの自動ガチャ

**🎲 Auto-gacha** を `On` にすると、指定した小節数ごとにシードを自動で引き直します。

- 小節数は右の数値欄で 1〜512 小節（既定 32）。1 小節 = 4 拍です。
- **BPM 値が出ている間だけ進みます**。BPM が `—`（未検出）のときは引き直されません。
  `SEARCH…` 中でも BPM の仮の値が出ていれば小節は数えられるので、確実に曲の展開に合わせたいときは `LOCK` を確認するか `TAP` で合わせてください。
- URL の `?autogacha=1&gachabars=16` でも指定できます。

## テンポが関わるほかの機能

| 機能 | テンポとの関係 |
| --- | --- |
| Timeline の `+bars` イベント | テンポグリッドが **ロックしているとき（`LOCK` または `TAP`）だけ** 発火します。→ [Timeline パネル](../timeline/) |
| Scene Deck の小節単位の自動送り | メイン窓のテンポがロックしているとき（`LOCK` または `TAP`）だけ進みます。→ [Scene Deck](../../live/scene-deck/#自動送り) |
| 映像の速さ | ロック中（`TAP` を含む）はテンポに合わせて 0.7〜1.25 倍に変わります。→ [Semantic Synth のしくみ](../semantic-synth/) |
