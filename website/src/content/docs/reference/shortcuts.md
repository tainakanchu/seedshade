---
title: キーボードショートカット
description: メイン窓と Scene Deck の窓のキーボードショートカット一覧。
---

どちらの窓でも、テキスト入力欄・選択欄にフォーカスがあるときと、`Ctrl` / `Alt` / `⌘` を押しながらのときは反応しません。

## メイン窓

| キー | 動作 |
| --- | --- |
| `H` | パネル（コントロールパネル + Timeline パネル）の表示 / 非表示 |
| `F` | フルスクリーン切り替え |
| `B` | 背景を黒 ⇄ 透過 |
| `R` | シードを引き直す（🎲） |
| `D` | 同じ構成のまま細部だけ引き直す（🧬） |
| `S` | Scene Deck の窓を開く（開いていれば手前に出す） |
| `T` | タップテンポ |

シード入力欄では `Enter` で確定します。

## Scene Deck の窓

| キー | 動作 |
| --- | --- |
| `1`〜`8` | スロットを出す（選択中の遷移プリセットで） |
| `Shift` + `1`〜`8` | スロットを `cut` で出す |
| `←` `→` `↑` `↓` | カーソル移動（4 × 2） |
| `Enter` / `Space` | カーソル位置のスロットを出す |
| `X` | 遷移プリセットを `cut` → `default` → `slow` で切り替え |
| `Q` | シードを引き直す（メイン窓の `R` 相当） |
| `W` | 細部だけ引き直す（メイン窓の `D` 相当） |
| `B` | 背景を黒 ⇄ 透過 |
| `H` | Hue 固定 ⇄ サイクル（固定に入るときは今の色相で固定） |
| `[` / `]` | 固定 Hue を -15° / +15° |
| `T` | タップテンポ |
| `,` / `.` | テンポを ÷2 / ×2 |
| `/` | テンポを自動検出に戻す（AUTO） |
| `L` | Timeline を今から 30 秒ロック ⇄ 解除 |
| `A` | 自動送り ON / OFF |
| `M` | 自動送りの単位（秒 ⇄ 小節） |
| `-` / `=` | 自動送りの間隔を減らす / 増やす（テンキーの `-` / `+` も可） |
| `R` | メイン窓の今の Patch からバンクを作り直す |
| `G` | BASE はそのままバンクの乱数だけ引き直す |
| `Shift` + `S` | 今の手札を次の空きスロット（無ければ `A`）に保存 |
| `F` | Deck の窓のフルスクリーン |
| `Esc` | MIDI learn を終了 |

:::note[日本語（JIS）配列のキーボード]
Deck のキーは文字ではなく、キーの物理的な位置（US 配列基準）で判定しています。
JIS 配列では `[` → **`@`** キー、`]` → **`[`** キー、`=` → **`^`** キーの位置になります。`,` `.` `/` `-` は刻印どおりです。
`1`〜`8` はキーボード上段の数字キーです（テンキーの数字は使えません）。
:::

### マウス操作（Deck）

| 操作 | 動作 |
| --- | --- |
| スロットをクリック | そのスロットを出す |
| `A`〜`H` をクリック | その手札を呼び出す |
| `A`〜`H` を `Shift` + クリック | 今の手札を保存（上書き確認なし） |
| `A`〜`H` を右クリック / 長押し | 手札の名前を編集 |
